Sources & Method

How this guide is written. Every trophy entry in the Atlas is written in our own words for this guide. The only text reproduced verbatim is the official material itself — each trophy's name, description and grade, shown exactly as PlayStation publishes them and labelled “Official description (PlayStation)” in the tracker. Everything beyond the official text — what to do, in what order, and when it can be missed — either carries a named source in the trophy's Sources block, or is labelled an Atlas method note: steps arranged from the official description alone, offered as method rather than as verified fact.

Data provenance. The trophy data is the official PlayStation 5 list for Grand Theft Auto VI: 55 trophies — 1 platinum, 2 gold, 6 silver, 46 bronze — with names, descriptions, grades and tracked counts as published. Before this bounty opened, the same list was cross-checked on Exophase and PSNProfiles; both agree on all 55 names, descriptions and grades, and the Atlas data follows that agreed list exactly.

Honesty note. Grand Theft Auto VI is a new game and this guide is new with it. Where a trophy's official description is cryptic — a joke, a riddle, a single line — the Atlas says so on that trophy's page, explains the reading it has adopted, and marks its steps as a method note instead of inventing a location or a trigger no source supports. Missable flags are reasoning from the official descriptions (a “final mission for” a character, a one-time departure, an arrival scene), stated on each flagged trophy so you can judge the reasoning yourself.
